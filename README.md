## Installation

**System Requirements:**
- macOS **14 Sonoma** or later
- Apple Silicon or Intel Mac

---

Build Better Notch from this fork using the steps in [Building from Source](#building-from-source).

## Usage

- Launch Better Notch and hover over the notch to expand it.
- Use the music controls to play, pause, skip tracks and scrub through playback.
- Open Settings from the menu bar or the notch to choose a music source and tune notch behavior.

## Focus

Better Notch keeps the experience centered on the notch and live music playback, with only the settings needed to customize those essentials.

## Building from Source

### Prerequisites

- **macOS 15.6 or later**
- **Xcode 26 or later**

### Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/harshilarora250/thebetter.notch.git
   cd thebetter.notch
   ```

2. **Open the Project in Xcode**:
   ```bash
   open boringNotch.xcodeproj
   ```

3. **Build and Run**:
    - Click the "Run" button or press `Cmd + R`. Watch the magic unfold!
